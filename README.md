# 空洞ちゃん (Kudo-chan)

空洞ちゃんのインタラクティブなWebアプリケーションです。

## 機能
- **歩く・走る**: 足取りに合わせて音楽が鳴ります。
- **水を飲む**: 水飲み場が現れ、みんなで水を飲みます。
- **分身**: ポンッという音と共に空洞ちゃんが増殖します。
- **撫でる**: 空洞ちゃんをクリックすると、嬉しそうに飛び跳ねて音が鳴ります。
- **移動指示**: 背景をクリックすると、一斉にそこへ向かいます。

## 遊び方
`index.html` をブラウザで開くだけで遊べます。

## GitHub Pages での公開方法
1. GitHubのリポジトリ設定 (Settings) を開きます。
2. 左メニューの `Pages` をクリックします。
3. `Build and deployment` の `Source` を `Deploy from a branch` に設定します。
4. `Branch` を `main` (または `master`) に設定し、`Save` をクリックします。
5. 数分後、画面上部に表示されるURLから誰でもアクセスできるようになります！
